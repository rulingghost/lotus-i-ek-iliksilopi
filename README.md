# 🌸 Lotus Çiçekçilik | Silopi Premium Web Sitesi

## ✨ Öne Çıkan Özellikler

- 👑 **Premium Görsel Dil:** Derin kömür/koyu zümrüt zeminler, lüks altın ve gül pembesi geçişleri ve cam efekti (glassmorphism).
- 📱 **Mobil Uygulama Hissiyatı:** Mobil ekranlar için özel alt navigasyon çubuğu (Bottom Navigation Bar) ve parmak dostu interaktif bileşenler.
- 💬 **Akıllı WhatsApp Asistanı:** Müşterilerin tek tıkla konum alma, araç süsleme veya buket fiyatı sorma gibi hazır mesaj şablonlarıyla otomatik yönlendirilmesi.
- 🏺 **Dinamik Katalog:** Buket, Çikolata, Yapay Çiçek, Aranjman, Araç Süsleme ve Saksı Çiçekleri gibi kategoriler arasında sıfır gecikmeli geçiş.
- 📝 **Özel Sipariş Form Sihirbazı:** Form bilgilerini (isim, tarih, bütçe, kart notu) anında şık bir WhatsApp sipariş fişine çevirerek iletme özelliği.

## 🚀 Kurulum ve Yayınlama

### Vercel ile Yayınlama
Bu proje tamamen saf **HTML, CSS ve JavaScript** kullanılarak geliştirilmiştir. Vercel üzerinde yayınlamak için:
1. GitHub deponuzu Vercel hesabınıza bağlayın.
2. Projeyi seçip varsayılan ayarlarla (Build Command ve Output Directory boş kalacak şekilde) **Deploy** butonuna basın.
3. Birkaç saniye içinde siteniz dünya çapında yayına girecektir.
